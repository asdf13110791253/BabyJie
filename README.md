# ProBilliards AI - 智能台球辅助系统

[![Android](https://img.shields.io/badge/Android-9.0%2B-green.svg)](https://www.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-100%25-blue.svg)](https://kotlinlang.org)

一个基于Android的智能台球辅助应用，使用计算机视觉技术实时分析台球桌面。

## 功能特性
- 🎯 悬浮球控制
- 📐 多类型辅助线
- 🎱 AI智能推荐
- 📊 力度估算
- 🔍 识别区域调整

## 技术栈
- Kotlin 100%
- MVVM + Hilt + Coroutines
- OpenCV for Android
- MediaProjection API
